# React UI Demo

A UI demo project built with React, Vite, TypeScript, Lucide React icons, and pure CSS Modules.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Subeesh4020/react_ui_demo
   ```

2. **Navigate into the project folder:**
   ```bash
   cd react_ui_demo
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
5. **Open the app in your browser:**
   Once the dev server is running, click the local URL link shown in your terminal (usually `http://localhost:5173`) or copy and paste it into your web browser to view the running app.
